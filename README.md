# BOBLIX

Своя игра в стиле Roblox на Godot 4: платформер с 8 режимами и сетевой игрой до 8 человек.

## Скачать

Сборки лежат в [Releases](https://github.com/dimacultasov6-star/boblix/releases):

- **Windows** — `BOBLIX.exe`, один файл, установка не нужна.
- **Android** — `BOBLIX.apk`, нужно разрешить установку из неизвестных источников.

Страница для друзей: <https://dimacultasov6-star.github.io/boblix/>

## Что внутри

- 8 режимов: паркур, арена, монетный дождь, лазеры, огонь, лёд, бомбы, вертушка
- 26 уровней с чекпоинтами, рекордами и монетами
- Сенсорное управление на телефоне: джойстик, прыжок, бег, обзор пальцем
- Сетевая игра до 8 человек
- Магазин с прокачкой и одеждой персонажа

## Управление

| Действие | Windows | Android |
|---|---|---|
| Ходьба | `WASD` | джойстик слева внизу |
| Прыжок | `Space` | зелёная кнопка справа внизу |
| Бег | `Shift` | синяя кнопка справа внизу |
| Камера | мышь | свайп в любой точке справа от джойстика |
| Пауза | `Esc` | кнопка `II` сверху справа |

## Сеть

Порт `27015`. В одной Wi-Fi сети игра подключается сама. Через интернет
нужен проброс порта на роутере.
