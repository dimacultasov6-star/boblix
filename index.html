Как играть с другом: запусти у себя любой режим — игра сама откроет сервер и покажет твой IP.

Друг вводит этот IP в поле «Подключиться к другу» и жмёт кнопку.

В одной Wi-Fi сети работает сразу. Через интернет нужен проброс порта 27015 на роутере.

Ставишь Android впервые? Телефон спросит разрешение на установку из неизвестных источников — открой .apk, согласись, включи «Установка неизвестных приложений» для того приложения, из которого открываешь файл, и вернись к установке. Обновляешь старую версию — сначала удали её с телефона, потом ставь новую.

Windows может ругаться на файл — это нормально для игры, скачанной не из магазина. Нажми «Подробнее» → «Выполнить в любом случае», или добавь файл в исключения Защитника.
